# US state reference calendars

Saved JSON calendars from [python-holidays](https://github.com/vacanza/holidays),
covering all 50 states and Washington, DC for 2020–2026. These are generated by an
external implementation, not the PHP providers and not an official government feed.
Territories are excluded. Public holidays may apply specifically to state government
employees; the data does not establish time-off entitlements for every employer.

Each calendar contains `subdivision` (US postal code), `year`, `actual` (without
substitute days) and `withObserved` (original dates plus observed/substitute dates).
Both lists contain `{date, name}` entries. A name can combine several holidays on
the same date, as returned by upstream. Calendars include only dates in the requested
year. Adjacent years are calculated to retain substitute days crossing New Year.

`source.json` records package version, source URL, license, language, category,
subdivisions, years, generation time and the SHA-256 hash of the JSON bytes. The
exporter rejects mismatched package versions and invalid/incomplete scope before
replacing the snapshot. Version and dependency pins must be changed intentionally
when adopting a newer upstream release. Review upstream changes and the resulting
data diff; regenerating a pinned release alone does not fetch newer holiday rules.

## Update locally

Python 3.11+ and the pinned dependencies are needed only for updating:

```bash
python3 -m venv /tmp/holiday-us-reference
/tmp/holiday-us-reference/bin/pip install -r tests/Reference/Usa/requirements.txt
USA_REFERENCE_PYTHON=/tmp/holiday-us-reference/bin/python php tests/console test:reference:usa:update
```

Alternatively, run `/tmp/holiday-us-reference/bin/python tests/Reference/Usa/update.py`
without PHP. Package installation needs internet; generation works offline afterwards.
The `reference-updater` Docker target includes the dependencies and sets
`USA_REFERENCE_PYTHON`. The aggregate `test:reference:update` command includes this source.

## Validation and current limits

```bash
php vendor/bin/phpunit tests/Reference/Usa
/tmp/holiday-us-reference/bin/python -m unittest discover -s tests/Reference/Usa -p 'test_*.py'
```

PHP checks the saved snapshot's checksum, coverage, dates and structure offline,
without Python. Python tests check export determinism, sample state-specific dates,
the New Year boundary and preservation of saved files on invalid configuration.
**There are no PHP state providers yet**, so these tests do not assert agreement
between state calendars and the PHP library. The existing `Usa` provider remains
federal-only. The files provide reference material for implementing state providers.
